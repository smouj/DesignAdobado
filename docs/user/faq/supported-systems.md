---
title: Which systems does DesignAdobado run on?
description: DesignAdobado source is configured for desktop and web targets; tested installation packages are not yet available.
order: 20
---

The source repository contains build targets for Windows, macOS, Linux, and web. Those targets are
not the same as tested installation packages: the current Adobado-branded build is still being
validated.

- **Windows**, **macOS**, **Linux**, and **web** are source build targets; behavior has not been
  confirmed in a current Adobado package.

Check [DesignAdobado releases](https://github.com/smouj/DesignAdobado/releases) and use a package
only when its release notes identify it as tested. See [Install DesignAdobado](../getting-started/install.md).
